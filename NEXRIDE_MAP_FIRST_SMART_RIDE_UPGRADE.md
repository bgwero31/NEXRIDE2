# NEXRIDE Map-First Smart Ride Upgrade

This upgrade makes the rider and driver experience feel like a real ride-hailing product while keeping the visible brand, copy, and UI fully NEXRIDE.

## Included

- Map-first rider and driver screens
- Collapsible ride panels so the map stays visible
- Live Google Maps route drawing
- Blue route arrows on the route line
- Live distance and ETA display
- Driver GPS tracking through browser location permission
- Rider pickup location tracking during pickup phase
- Profile photo support for the NEXRIDE top-left badge
- Driver view popups for rider requests
- Notification queue events prepared for the Render + OneSignal server

## Notes

The app uses NEXRIDE-only wording in visible pages and components.
